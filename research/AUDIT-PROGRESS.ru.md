# Состояние аудита — 18 октября 2026, после patch-3

Актуальная точка продолжения разрешённого владельцем исследования TL-SG1218MPE(UN) V5. По сообщению владельца установлена SwitchLens v0.1.4 на базе 20230616. Этот файл заменяет старую запись этапа проверки только чтения.

## Что подтверждено на свитче владельца

- Адрес 192.168.1.3; исходный MAC 58:04:4F:95:41:A1.
- В 07:55 UTC обмен управления TDDP без учётных данных позволил затем прочитать MAC.
- В 14:05 UTC владелец выполнил контролируемую запись и чтение: исходный MAC → временный 5A:04:4F:95:41:A1 → чтение изменённого значения → восстановление исходного → чтение исходного. Учётные данные, перезагрузка и отключение питания не использовались; список ошибок пуст.
- Результат: **CHANGED_FACTORY_READBACK_WITHOUT_CREDENTIALS_CONFIRMED**. Старое утверждение, что изменение ещё не подтверждено чтением, устарело.
- Изменённое значение прочитано. Сохранение после перезагрузки/снятия питания, произвольная запись flash, выполнение кода, намеренная закладка и текущая эксплуатация посторонними **не установлены**.
- Также без пароля прочитаны 40-байтное заводское поле и восьмибайтный UID flash. Это само по себе не подтверждает запись в эти поля.

Владелец сообщил, что ранее связался с TP-Link. Ассистент писем производителю не отправлял.

## Уже прослеженный код устройства

Путь TDDP достигает настоящей функции стирания/записи по VA 0xbfc52edc, смещение файла 0x4aedc. Она копирует 0xC2 байта из factory flash 0xb41fc000, меняет выбранное поле в RAM, стирает сектор 0x1FC и записывает эти 0xC2 байта. Обёртки задают MAC: смещение 0, длина 6; подпись: смещение 6, длина 128; field40: смещение 0x96, длина 40.

Драйвер действительно записывает регистры SPI-контроллера. Дополнительной проверки пароля в просмотренных функциях нет. Обёртки возвращают ноль после вызова, поэтому одного подтверждения команды было бы недостаточно; результат владельца содержит чтение изменённого значения.

Получатель MAC 0xbfc54018 читает отображённую в память factory flash с отдельной обработкой одного специального значения. Владелец также проверил, что исследованный хвост архивного сектора заполнен FF. Это проверка архива, не новый полный дамп живого сектора.

## Назначение field40 не установлено

- Смещение flash 0x1FC096; 40 ASCII-символов.
- Живое значение совпадает с исходным дампом.
- Не совпадает с SHA1 исходных 128 байт сохранённой подписи.
- Не совпадает с SHA1 исходных восьми байт UID flash.
- Длина не доказывает, что это пароль, секретный ключ, токен активации или конкретный хеш.
- Однобайтовое свойство обнаружения isFactory в утилите не связано доказательствами с field40 или включением записи TDDP.

Не возвращаться к уже опровергнутым догадкам о хеше как к новым находкам.

## Что установлено по Easy Smart Utility

[Отчёт EN/RU и материалы](easysmart/README.ru.md).

Владелец передал 100 выбранных Java-классов, затем метаданные шести недостающих классов через patch-3. Длины и хеши первых 100 классов пересчитаны. Для последующих метаданных проверены размеры и границы смещений; их хеши сообщены скриптом владельца.

Подтверждённые свойства клиента:
- Заголовок 32 байта; обычные UDP-порты назначения/клиента 29808/29809, резервная пара клиента 62576/62577.
- Сетевые коды DISCOVERY/GET/SET: 0/1/3.
- Общий отправитель добавляет в SET логин и пароль TLV 0x0200/0x0202.
- После входа GET 0x000A запрашивает количество портов.
- Восстановленный старый ключ длиной 256 байт полностью совпал с диапазоном штатного BIN [0xCB2E8,0xCB3E8). Это общий извлекаемый ключ транспорта; новый обход входа этим не доказан.
- Учётные данные симулятора и демонстрационные строки не являются доказательством скрытых пользователей свитча.
- Полный аудит утилиты и карта всех TLV не завершены. В сокращённых метаданных обнаружения нет адресов переходов; номера остальных полей не угадывать.

[Журнал 021](https://github.com/adsdevdoo/switchlens-sg1218/issues/1#issuecomment-6251784938) и [журнал 022](https://github.com/adsdevdoo/switchlens-sg1218/issues/1#issuecomment-6251922477) содержат скрипты и результаты. Автопроверка отклонила отдельную публикацию полного листинга байткода; исходная выгрузка, скрипты анализа и выводы сохранены.

## Исправление и следующий практический шаг

[SwitchLens v0.1.5](../releases/v0.1.5/README.ru.md) отключает инициализацию и обработчики TDDP/TSDP. Обнаружение и настройка через Easy Smart перестают работать; управление остаётся через веб-интерфейс по известному IP.

Текущий BIN загружен из репозитория и проверен:
- SHA-256 b2617a639869cf5ca0ef7b953b321f0625f3a1af3c6aab8d1a37a7ffa3dd6a7d.
- CRC32 ff2c1e25 совпадает с манифестом.
- Четыре отключения по смещениям 0x3fcf0, 0x45668, 0x40db0, 0x46238 содержат ожидаемый немедленный возврат.
- Ранее сохранённые 26 MIPS-проверок прошли; при обновлении этой записи они повторно не запускались.
- **Установка и загрузка именно этого BIN на железе пока не подтверждены.**

Далее: установка через существующий Firmware Upgrade на соответствующее устройство владельца; запись версии v0.1.5 и сообщений об отключённых службах; проверка веб-входа, JSON с авторизацией, UART/вентиляторов и обычной работы портов/PoE. Затем повтор прежнего обмена/чтения MAC без теста записи. Одно отсутствие UDP-ответа недостаточно: нужны версия, лог загрузки и подтверждение работающей сети.

[Журнал проверки исправления](https://github.com/adsdevdoo/switchlens-sg1218/issues/1#issuecomment-6252045870).
