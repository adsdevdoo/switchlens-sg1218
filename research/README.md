# Research records

These documents preserve the investigation history. **Current status:** working
v0.1.1 firmware has booted after stock web upgrade, accepted UART help and returned
two changing JSON replies on the owner's unit. [Evidence](../docs/evidence/2026-10-17-switchlens/README.md).
Earlier statements such as “no image built,” “UART unavailable” or “not flashed”
describe their original analysis date, not current status.

`mib-map.json` comes from limited instruction tracing with mocked registers,
not real ASIC measurement. `metric-sources.json` maps fields to evidence and
unknowns. `platform-evidence.json` is generated by `tools/audit_platform.py`.
Earlier inability to compare versions was superseded when vendor files became
available; that does not establish every bootloader check or downgrade path.

[Vendor ZIP/BINs](../vendor/tp-link/tl-sg1218mpe-v5/README.md),
[datasheets](../docs/datasheets/README.md), [bench](../docs/LAB.md).
Full disassembly outputs mentioned in reports are not tracked. Generate them
with hash-pinned read-only audit/disassembly tools:

```bash
python3 tools/disassemble.py /path/image.bin 0x37388 0x376f8
python3 tools/disassemble.py /path/image.bin 0x49e18 0x49e78
```

Offsets include the 16-byte update header; end offsets are excluded.
Disassembly alone does not establish a function's hardware semantics.
