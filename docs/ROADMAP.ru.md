# Этапы SwitchLens

Состояние **17.10.2026 после первого аппаратного испытания v0.1.1**.
[Материалы опыта](evidence/2026-10-17-switchlens/README.ru.md),
[справочник JSON](JSON-API.ru.md), [контекст для продолжения](CONTEXT.ru.md).

| --- | --- |

Текущий приоритет — [анализ путей охлаждения и полезного мониторинга GPIO26](../research/COOLING-PATHS.ru.md).
Активный тест GPIO27=0 подтверждён; явного улучшения работы вентиляторов нет. RPM неизвестны.

Дальнейшие аппаратные проверки — реальный PoE-потребитель и сравнение JSON
со штатной страницей. Одновременно уточнять физическую нумерацию и настройки
портов, причину `rx_bridge_discards`, единицу uptime. Два ручных JSON не
устанавливают допустимую частоту постоянного опроса.

Один свитч пока не введён в эксплуатацию. Первый успешный запуск не закрывает
испытания восстановления и устойчивости. Владелец осознанно продолжил
web-обновление без повторной выпайки; не превращать старый план проверки
программатором в новое обязательное условие продолжения.

Официальные ZIP/BIN — [архив TP-Link](../vendor/tp-link/tl-sg1218mpe-v5/README.ru.md),
даташиты — [каталог](datasheets/README.ru.md), границы реализации/эмуляции —
[FIRMWARE](FIRMWARE.ru.md). Неподтверждённые поля остаются `null`,
экспериментальные счётчики не объявляются эквивалентом IF-MIB.
