# Финальная проверка v0.1.1-experimental-uart

Дата: 17.10.2026. Проверен BIN из коммита `35030053d838aefb860b5dd5088d4ff1db210740`.
**Ошибок в выполненных проверках не обнаружено. BIN не менялся.**
Это исторический отчёт до аппаратного запуска. Позднее загрузка, UART help
и JSON подтверждены: [материалы](evidence/2026-10-17-switchlens/README.ru.md).
[Неизменённый артефакт выпуска](../releases/v0.1.1-experimental-uart/FINAL-CHECK.md).

SHA-256: `27e4fce8d5c0c2999a324341cea7e96e37b1c0561e8d6a3218705b32b7aeee71`.

## Целостность и происхождение

- Файл скачан по публичной ссылке GitHub Raw и побайтово совпал с выпуском.
- Повторная упаковка в отдельном каталоге дала тот же BIN.
- Размер: 1 013 324 байта; CRC32: `5c6abcf2`, покрытие `[0x10, 0xf7000)`.
- Заголовок после поля CRC и хвост `[0xf7000, EOF)` совпадают с официальным BIN.
- Payload `/stats.json` побайтово совпадает с v0.1.0. Хеши его исходников
  совпадают с сохранённым манифестом.
- От v0.1.0 изменились **10 байтов** внутри двух 4-байтовых инструкций UART
  и 4-байтового поля CRC. Остальные байты прежнего выпуска сохранены.
- От официального образа изменились 12 120 байтов; все изменения находятся
  в CRC, двух HTTP-переходах, двух UART-инструкциях и области payload.
- Исходный SPI-дамп, официальные BIN и прежний выпуск не изменены.

## Дополнительная проверка загрузчика

Исполнена функция из исходного SPI по смещению `0x1898`, RAM VA `0xbf0031a0`,
с исходной CRC-функцией `0xbf002ebc`. Начальное состояние: рабочий заголовок
обнулён, новый BIN расположен в staging `0xb4100000`, как после найденной
ветви web-обновления. Инициализация flash, изменение режима, копирование
во flash и диагностическая печать заменены моделью; это не проверка записи SPI.

Для нового BIN эта ветвь проверяет заголовок/CRC, запрашивает копирование
ровно 1 013 324 байтов в `0xb4008000` и достигает входа runtime `0xb4008010`.
Модель сохраняет загрузчик и область `[SPI 0x1fc000, 0x200000)`.
Порча одного байта staging приводит к отказу **до вызова копирования**.

Эта проверка уточняет прежнее «проверки загрузчика неизвестны» для одной
прослеженной ветви сохранённого дампа. Она не доказывает успешность всей
загрузки, физического обновления, восстановления или отсутствие иных ветвей.
Код runtime после входа и аппаратный `SignCheck` здесь не исполнялись.
