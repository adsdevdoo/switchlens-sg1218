## Подключение UART

1. Пайка и перестановка проводов — при отключённом питании и USB-UART.
   На другой плате сначала прозвонить цепи R41/R42, не замыкать любые пустые места.
2. Подключить подтверждённую землю к GND адаптера, **pin 1 J2 к RXD адаптера**.
   Для ввода команд pin 2 RX свитча подключён к TXD адаптера; использовать
   совместимые логические уровни. VCC, 3V3, 5V адаптера к свитчу не подключать.
   Выбор 3,3 В на адаптере сам по себе не является измерением уровня TXD.
3. Закрыть PuTTY перед запуском `tools/start-uart.cmd`. По умолчанию COM3,
   **38400, 8N1**, 60 секунд. После `LISTENING` включить стенд. См. [инструкцию](UART-CAPTURE.ru.md).

## UART CLI: уточнение по статическому анализу

[Проверено по дампу](../research/UART-CONSOLE.ru.md): bit 0 слова `0xbfcff018`
равен нулю; периодический обработчик обходит чтение UART и CLI.
Отсутствие ответа на Enter ожидаемо по этому пути и не проверяет пайку RX.
Подготовлен отдельный [диагностический образ](../releases/v0.1.1-experimental-uart/README.ru.md),
в котором диспетчер и разрешения CLI включаются двумя инструкциями в коде.
На устройстве после web-обновления получены `RTK#` и ответ на `help`;
[оригинальные материалы](evidence/2026-10-17-switchlens/README.ru.md).
Путь восстановления программатором не зависит от интерактивной консоли runtime.

## После первого успешного запуска

Первое web-обновление уже выполнено. Опубликованы восемь скриншотов,
присланный загрузочный лог, help, оба JSON и сравнение:
[журнал успешного испытания](evidence/2026-10-17-switchlens/README.ru.md).

1. Сравнить JSON со штатной панелью и проверить PoE с реальным потребителем.
2. Проверить нумерацию портов, настройки, изменение счётчиков и причину discards.
3. Установить единицу raw uptime измерением по внешнему времени.
4. Испытать опрос под нагрузкой, обрывы клиентов и длительную работу.

Восстановление пока не проверено. Владелец отказался от повторной выпайки
ради предварительного теста; не предлагать её заново как обязательный этап.
Экспорт Xgpro длиннее массива SPI на 272 байта, официальный update BIN
не является полным дампом. UART/TFTP recovery и команды загрузчика не установлены.

Блок питания содержит сетевое напряжение; работа с его первичной стороной
не требуется. Эксперименты на введённом в эксплуатацию оборудовании не проводятся.
Материалы первого успешного запуска сохранены по прямому запросу владельца; будущие сеансы
не публикуются автоматически.
