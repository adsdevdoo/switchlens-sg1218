# Этапы SwitchLens

Проверено по текущим исходникам и журналам: офлайн-прототип готов; внедрения в
HTTP-роутер и испытаний на железе ещё нет.

| Этап | Статус / критерий |
|---|---|
| Статический анализ runtime | Частично выполнен; факты и неизвестные — `research/` |
| Контракт JSON и host-прототип | Проверено локальными тестами |
| Загрузчик, подпись, RAM/flash | Не закрыто; нельзя объявить возможность прошивки доказанной |
| Стенд V5.0 | Нужны UART, полный SPI-дамп и проверенное восстановление |
| Адаптер HTTP/RAM/ASIC | Предстоит; нужна целевая MIPS-сборка и linker map |
| Минимальный `/stats.json` | Предстоит, сначала только на стенде |
| Недельное испытание | Предстоит: нагрузка, реальные PD, PoE, память, HTTP, откат |
| Боевой коммутатор | Отдельное решение владельца после предыдущих этапов |

Условия «можно» для изменённого образа: проверка целостности/подписи проходима
без изменения загрузчика; места для кода и стека достаточно; функции чтения
и HTTP-отправки проверены; есть испытанный путь восстановления. Наличие FF
в образе и успешная host-сборка сами по себе эти условия не подтверждают.

Первый адаптер: System Info и PoE из штатного RAM-кэша, затем byte counters
и отдельные MIB-счётчики. Неизвестные поля остаются null. SNMP в текущую цель
не входит. Образ собирается воспроизводимым скриптом только из ожидаемого SHA-256.
