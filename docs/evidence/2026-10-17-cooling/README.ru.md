# Подтверждённое управление скоростью обоих вентиляторов

## Аппаратное подтверждение — 17 октября 2026, 21:46 Europe/Belgrade

Владелец заменил вентилятор, требовавший толчка, на штатный. Оба установленных
вентилятора теперь нормально вращаются; `cool test 0` **ускоряет оба**. Первое
упоминание `cool test 1` владелец исправил на `cool test 0`.

Это подтверждает общее воздействие GPIO27=0 на скорость обоих вентиляторов
данного устройства. Наблюдение заменяет прежние неопределённые результаты и
гипотезу, что выход только включает второй вентилятор. Оно не устанавливает RPM,
напряжение питания, электрическую схему, предельную скорость или причину проблем
запуска снятого вентилятора. Не описывать текущую конфигурацию как один стоящий
вентилятор и не считать, что оба установленных вентилятора — Noctua. Точная
текущая модель другого вентилятора здесь не уточняется.

JSON v0.1.2 уже содержит `cooling.gpio27_level` и `cooling.mode`. Для проверенного
устройства потребитель может подписывать корректный выходной уровень GPIO27=0
как **запрос повышенной скорости**, а 1 — **запрос пониженной скорости**. Это
заданный режим, не измерение вращения или исправности. Проверять mux/direction
GPIO; null/некорректное состояние не считать пониженной скоростью. `fan_rpm` и
`fan_status` оставить неизвестными. `mode=auto` обозначает алгоритм управления,
а не скорость: автоматика может выбрать любой уровень. Схема JSON и BIN не менялись.

Текущее действие: `cool auto` возвращает штатное управление по нагрузке PoE;
существующие поля подходят для мониторинга режима. Стартовый разгон и повторные
тесты GPIO для решения проблемы уже заменённого вентилятора не нужны. Точная
калибровка таймера остаётся отдельной задачей и больше не требуется для
подтверждения влияния выхода на скорость.
