# UART: доказательства от 17 октября 2026

Материалы включены по прямому запросу владельца: сохранить все присланные
UART-логи и скриншоты в репозитории и README. Это узкое исключение из обычного
правила о локальном хранении журналов. Текст содержит MAC данного экземпляра.

- **Проверено по сообщению владельца:** R41/R42 прозвонены как последовательные
  разрывы, рабочая доработка — по **0 Ом, 0402**; **pin 1 — TX свитча**.
- **Проверено по сообщению «38400 отлично работает» и читаемому выводу:**
  рабочая скорость **38400**. Использовались 8N1, без управления потоком.
- [boot-stock-38400.txt](boot-stock-38400.txt) — полный текст, вставленный
  владельцем в чат: от `check runtime img` до ` code init !---------- Done!`.
  Все строки и MAC сохранены; файл записан UTF-8 с LF. Это текстовая копия,
  не побайтовая запись UART. Исходный `rx.bin` и `session.json` не получены.
- Скриншоты скопированы без изменений; исходные имена и SHA-256 перечислены
  в [sources.json](../../images/sources.json). Они встроены в
  [главный README](../../../README.md#uart-на-стенде).
- Нулевые захваты доступны только как скриншоты. Второй нулевой захват относится
  к **pin 1**, согласно исправлению владельца, а не к pin 2. Файлы приёма
  для этих сеансов не присылались; бинарные журналы из картинок не реконструировались.
- **Не проверено:** ввод команд, RX свитча, меню загрузчика, восстановление,
  загрузка модифицированного BIN. `SignCheck Pass.` относится к штатной загрузке
  и само по себе не доказывает принятие изменённой прошивки.

Нумерация J2 — нумерация владельца в измерениях. Привязка номеров к ориентации
фото и заводскому маркеру отдельно не установлена; не переносить её на другую плату.
