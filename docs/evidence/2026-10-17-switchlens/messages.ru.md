## Обновление и загрузка

Владелец прислал [System Info](02-system-info.png),
[форму обновления](03-upgrade-form.png), [прогресс 5%](04-upgrade-progress.png),
[перезагрузку](05-reboot-start.png), [завершение загрузки с RTK#](06-boot-rtk.png)
и полный текст [boot-after-upgrade.txt](boot-after-upgrade.txt).

Ключевой фрагмент присланного текста:

```text
check runtime img
Image erase all!
Image recover done!
check runtime img
go to runtime addr 0xb4008010
```

Далее присутствуют `SignCheck Pass.`, `RTK#` и завершение `code init`.

## Проверка ввода

Владелец ввёл `help` и прислал текст ответа и [скриншот](07-uart-help.png).
Полный текст, включая все перечисленные команды: [uart-help.txt](uart-help.txt).

```text
RTK# help
?       - alias for 'help'
acl     - acl configuration
help    - print online help
mib     - to get switch mib counter
```

Наличие команды в справке не означает её исполнение в этой проверке.
