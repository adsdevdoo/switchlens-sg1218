# Команды охлаждения — v0.1.3

| Команда | Действие |
| --- | --- |
| `cool low` | Пониженная скорость обоих, без таймера |
| `cool fast` | Повышенная скорость обоих, без таймера |
| `cool auto` | Штатная автоматика по PoE |
| `cool status` | Текущий режим и сырые сигналы входа/выхода |

Ручной режим сохраняется до следующей команды или перезагрузки. `cool test` удалена.
`auto` использует пороги <1460 и >=1501 в единицах 0,1 Вт; между ними сохраняется
предыдущее состояние. GPIO27=0 соответствует наблюдаемому ускорению. GPIO26
выбирает штатную индикацию; цвет, здоровье и RPM по нему не назначаются.
Настройка во флеш не записывается.

`cooling.mode`: auto/manual/invalid; `cooling.speed_mode`: low/fast/null.
JSON только читает и не переключает вентиляторы. В v0.1.3 endpoint открыт без входа.
