# SwitchLens v0.1.6 — статистика независимо от веб-сессии

[**Скачать BIN для web-обновления**](https://github.com/adsdevdoo/switchlens-sg1218/releases/download/v0.1.6/SwitchLens-SG1218MPE-V5-v0.1.6.bin)
· [BIN в репозитории](SwitchLens-SG1218MPE-V5-v0.1.6.bin)
· [SHA256SUMS](SHA256SUMS) · [Манифест](build-manifest.json)

Для **TP-Link TL-SG1218MPE(UN) V5.0**, база `1.0.0 Build 20230616 Rel.57668`.
Это функции и защита v0.1.5 плюс точный `GET /stats.json` без авторизации.
**Предварительный выпуск: установка и реальная одновременная работа панели
со сборщиком ещё не проверены.** Последняя подтверждённая установленная версия
— v0.1.4; аппаратная проверка подготовленной v0.1.5 была отложена.

## Что изменено

- Точный `GET /stats.json` не требует входа, пароля, cookie, токена или предварительного запроса.
- Исходная строка запроса проверяется до внешнего контроля IP/сессии и продления тайм-аута.
  Статистика не создаёт/заменяет сессию, не меняет cookie/IP и не продлевает срок.
- Панель, настройки, обновление и перезагрузка сохраняют штатную авторизацию.
  Query, похожие пути и другие методы исключения не получают.
- Схема 1, состав/значения метрик, тип JSON и no-store сохранены.
  Заголовок: `X-SwitchLens-Build: v0.1.6`; строка версии TP-Link не менялась.
- UART и `cool low/fast/auto/status` сохранены. Ручной режим действует до auto/перезагрузки.
- Сохранены четыре патча отключения инициализации/приёма TDDP/TSDP из v0.1.5
  и сообщения загрузки. Easy Smart не работает; управление — через web по известному IP.

В v0.1.3 патч выполнялся слишком поздно: внешний обработчик уже подменял путь
на `Unauth`. v0.1.6 меняет пролог по смещению `0x34e48` и проверяет исходные
метод/путь. Остальные запросы выполняют вытесненные инструкции и штатный код.
[Разбор HTTP, причина и проверки](../../docs/HTTP-AUTH.ru.md).

Сокеты/MMIO в MIPS-тестах синтетические. Проверено чередование запросов,

промежуточную запись; статически в пути статистики нет записей сессии.

## Установка и проверка Windows

1. Сверить хеш и загрузить BIN через штатную Firmware Upgrade. Обеспечить питание
   во время обновления. Этот BIN не является полным SPI-бэкапом.
2. После загрузки выйти из панели и выполнить без авторизации:

   ```powershell
   curl.exe --connect-timeout 5 --max-time 15 -D - http://192.168.1.3/stats.json
   ```

   Ожидаются JSON, `Content-Type: application/json`, v0.1.6 и отсутствие `Set-Cookie`.
3. Войти в панель на A. На B **с другим исходящим IP** сохранить
   [Test-AnonymousStats.ps1](https://github.com/adsdevdoo/switchlens-sg1218/releases/download/v0.1.6/Test-AnonymousStats.ps1)
   в `C:\tmp` и выполнить:

   ```powershell
   powershell -NoProfile -File C:\tmp\Test-AnonymousStats.ps1 -Switch 192.168.1.3 -Count 60 -IntervalSeconds 2
   ```

   Во время опроса открывать страницы панели: повторный вход не должен требоваться.
   Отчёт и последний JSON сохраняются в `C:\tmp`. Административные страницы с B
   должны требовать вход. Скрипт не авторизуется и не отправляет cookie.
4. Проверить v0.1.6 в `cool status`, сообщения отключённых служб, команды
   охлаждения, порты/PoE. Обычный тайм-аут сессии сохраняется: статистика
   не должна удерживать бездействующую панель в авторизованном состоянии.

Результат передать в текущем обсуждении разработки v0.1.6; issue #1 остаётся журналом аудита безопасности.
