# SwitchLens v0.1.0 — архивный выпуск с JSON

Первый пакет для TL-SG1218MPE(UN) V5.0 сохранён без изменения.
**Текущая рабочая прошивка — [v0.1.1](../v0.1.1-experimental-uart/README.ru.md)**:
она использует тот же JSON-payload и включает штатный UART CLI.
v0.1.0 отдельно на устройстве не испытывалась. Исторические имена файлов/тега сохранены.

- [BIN](SwitchLens-SG1218MPE-V5-v0.1.0-experimental.bin)
- [SHA256SUMS](SHA256SUMS), [манифест выпуска](release.json), [манифест сборки](build-manifest.json)

Динамический GET работает с существующей сессией и предоставляет сведения
о системе, 18 портах, счётчиках, PoE и Auto Recovery. Неизвестные значения — null;
семантика части дополнительных MIB остаётся гипотезой. Основа — официальная
1.0.0 Build 20230616 Rel.57668; внутренняя строка версии сохранена.

Офлайн проверены размер **1 013 324 байта**, SHA-256
`58d48cf69cac4024eddfb4ede1bb5a925420521a0f0e44011ff4fa08940c2e25`,
CRC32 `5e9ceeca` по `[0x10,0xf7000)`, поле по offset 0, совпадение исходников
с манифестом. [MIPS-результаты](../../docs/target-test-results.json),
[реализация](../../docs/FIRMWARE.ru.md).

Позднее на v0.1.1 подтверждены web-обновление/загрузка, RTK#/help и два JSON
на плате Ver:5.40. [Материалы](../../docs/evidence/2026-10-17-switchlens/README.ru.md).
Нагрузка PoE, длительная работа и восстановление ещё не проверены. Исходный
SPI-экспорт и штатный UART сохранены. Runtime CLI не доказывает recovery загрузчика.
Решение владельца не выполнять повторную выпайку для предварительного теста — [LAB](../../docs/LAB.ru.md).

```powershell
Get-FileHash .\SwitchLens-SG1218MPE-V5-v0.1.0-experimental.bin -Algorithm SHA256
```

```bash
sha256sum -c SHA256SUMS
```
